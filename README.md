A one-page site of my takeaways from DesignUp 2026, Bengaluru.

## Publish on GitHub Pages
1. Create a new public repository on GitHub, for example `designup26`.
2. Click **Add file → Upload files**, then **choose your files**. Open this folder, select every file (Cmd+A) and upload. There are no subfolders.
3. Commit the upload.
4. Go to **Settings → Pages**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, and save.
5. After a minute the site is live at `https://<your-username>.github.io/designup26/`.
